# Translating Alpöge’s formal proof of the Riemann hypothesis

The mathematical manuscript follows the released argument through Dirichlet-character nonvanishing to classical RH. Its last section lists the results that still need a proof in prose. Each completed manuscript release contains a PDF and a single LaTeX file that can be compiled without Lean. [Manuscript source](manuscript.tex) · [Manuscript releases](https://github.com/ChristianKudeba/alpoge-rh-verification/releases?q=translation-) · [Build and publication history](https://github.com/ChristianKudeba/alpoge-rh-verification/actions/workflows/rh-manuscript.yml)

The literal edition represents the Lean kernel’s proof terms in indexed mathematical notation. Its guide shows how to read the expressions, locate the target theorem and follow references across volumes. The full edition is being rendered on GitHub from the MIT-published solution export. [Reading guide](kernel/reading.md) · [Typeset sample](kernel/sample/kernel-00001.tex) · [Full edition build](https://github.com/ChristianKudeba/alpoge-rh-verification/actions/workflows/literal-kernel-edition.yml)
